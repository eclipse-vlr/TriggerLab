# TriggerLab

[![Сборка и тесты](https://github.com/eclipse-vlr/TriggerLab/actions/workflows/ci.yml/badge.svg)](https://github.com/eclipse-vlr/TriggerLab/actions/workflows/ci.yml)

Приложение для тренировок в Kovaak’s и Aimlabs: находит выбранный цвет возле прицела и отправляет один клик при наведении. Прицел вы наводите сами.

**Windows 10/11 x64 · C++20 · Win32 · без установки**

## Запуск

Скачайте ZIP из [последнего релиза](https://github.com/eclipse-vlr/TriggerLab/releases/latest), распакуйте и откройте **TriggerLab.exe**. **TriggerLabTrainer.exe** — отдельный встроенный тренировочный стенд.

`build-windows.bat` предназначен для сборки исходников. Для него нужны инструменты разработки, перечисленные ниже.

## Быстрый старт

1. Откройте тренировку в оконном режиме или без рамки.
2. Нажмите **«Выбрать окно»** и укажите тренажёр. **«Обновить список»** добавляет недавно открытые окна.
3. Нажмите **«Цвет из прицела (3 сек.)»**, наведитесь на мишень и выберите её цвет на снимке.
4. Нажмите **«Сохранить всё»**, затем **«Проверить цвет»**. Проверка распознаёт мишень без отправки кликов.
5. После успешной проверки нажмите **«Включить клики»**.

**F9 или «Остановить» полностью останавливают захват и ввод.** Нажимайте F9 перед переходом в меню тренажёра. Потеря фокуса при включённых кликах означает паузу; возврат в тренировку может возобновить работу.

На одно непрерывное совпадение приходится один клик. Следующий требует ухода с цвета и нового наведения. При запуске приложения клики выключены; после смены окна, цвета или параметров нужна новая проверка.

## Настройки и диагностика

- **«Из файла…»** выбирает цвет из PNG/JPEG/BMP/GIF/TIFF; **«Палитра / область»** уточняет участок изображения.
- **«Профили и диагностика»** сохраняет параметры под названием тренировки и сравнивает снимки мишени и фона.
- **«Расширенные»** открывает размер области, исключение перекрестия, порог и время срабатывания. Подсказка **«?»** объясняет каждый параметр.
- Клавиша **H** переключает RGB/HSV. В HSV поле RGB-допуска отключено. После изменений сохраните настройки и повторите проверку.
- **«Серая тема»** переключает светлое и тёмное оформление.

Настройки и профили хранятся в `%LOCALAPPDATA%\TriggerLab`. После остановки остаётся итог последнего запуска: свежие и недоступные кадры, совпадения в центре, максимальная доля цвета и последняя причина недоступности.

Цвет у края области сам по себе не разрешает клик: проверяется наведение центром. Область анализа должна целиком оставаться видимой; другие окна и оверлеи приостанавливают анализ. Сохранённые снимки используются для просмотра, а ввод требует свежих кадров.

Если Windows отклоняет отпускание кнопки, новые клики блокируются. F9 и служебный таймер повторяют попытку отпускания; обычное закрытие ожидает её подтверждения.

## Если не работает

- Активируйте выбранную тренировку и закройте её меню.
- Проверьте цвет на текущей мишени; при необходимости выберите заново и сохраните.
- При чёрном или недоступном снимке попробуйте оконный режим. Причина паузы показана в приложении.
- Ошибки BAT остаются в `build-windows.log`; ошибки запуска EXE — в `%LOCALAPPDATA%\TriggerLab\startup.log`.

Количество выстрелов зависит от того, как конкретный сценарий тренажёра обрабатывает нажатие. Методика ручной проверки: [docs/trainer-validation.md](docs/trainer-validation.md).

## Сборка и разработка

Нужны CMake 3.20+, Visual Studio 2022 или Build Tools 2022 с MSVC v143, Windows SDK и компонентом «Разработка классических приложений на C++».

```powershell
.\build-windows.bat
```

BAT собирает Release, запускает тесты и открывает приложение. При ошибке сохраняет лог и ждёт нажатия клавиши.

Переносимое ядро собирается на Linux без Windows-интерфейса:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
ctest --test-dir build --output-on-failure
```
