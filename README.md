# TriggerLab 0.4.0-preview.3 — тренировки Kovaak’s / Aimlabs

Windows x64 приложение для обнаружения заданного цвета вокруг прицела выбранного окна. Предусмотрены проверка без ввода и явно включаемый одиночный клик. Программа не перемещает прицел. Это предварительная сборка, совместимость зависит от сценария, режима окна и обработки ввода тренажёром.

## Запуск

Распакуйте ZIP и запустите **TriggerLab.exe** — теперь это основной анализатор. **TriggerLabTrainer.exe** — сохранённый отдельный тренировочный стенд v0.3.2 с русским/английским интерфейсом, сценами, прицелом и виртуальными выстрелами. Для совместимости в каталоге сборки остаётся также TriggerLabCapturePreview.exe, идентичный анализатору.

Windows 10 1703+ / Windows 11 x64, интерактивный рабочий стол. Visual C++ Runtime включён в exe. Установка и обязательные права администратора не требуются. Сборка не подписана сертификатом издателя.

## Настройка тренажёра

В простом режиме верхняя строка показывает готовность четырёх шагов. Большая кнопка в блоке «Следующий шаг» предлагает нужное действие.

1. Выберите окно кнопкой Kovaak’s / Aimlabs либо вручную за 3 секунды.
2. Возьмите цвет мишени кнопкой «Цвет из прицела (3 сек.)»: тренажёр активируется автоматически, наведите прицел на мишень, затем выберите её пиксель/область в снимке. Если открыто меню, возобновите свободную игру. Также доступны пипетка, выбор цвета и изображение. Перекрестие не должно быть выбранным цветом.
3. Нажмите «Сохранить всё», затем «Проверить цвет». Тренажёр активируется, срабатывания считаются без отправки кликов. Если открылось меню, возобновите свободную игру. Шаг проверки завершится только после совпадения с выдержанной задержкой.
4. После успешной проверки кнопка предложит «Включить клики». Одно непрерывное совпадение даёт один клик. F9 останавливает захват и ввод; перед входом в меню нажмите F9.

Поиск цвета и задержки не перемещает прицел. Изменение цвета, окна или параметров требует повторной проверки. Кнопка «Расширенные» раскрывает ручной RGB, размер области, исключение центра, порог, сдвиги и время нажатия. В этом режиме сохранены отдельное управление захватом и переключатели проверки/триггера.

Если Kovaak’s открывает меню при переключении окон, возобновите игру до окончания отсчёта съёмки. Для настройки можно временно отключить «Видео → Пауза при потере фокуса», затем вернуть её после проверки. Цвет берите из свежего снимка текущей мишени: сохранённый оттенок другого сценария может не подойти.

На снимке рамкой обозначена область обнаружения, штриховкой — исключённое перекрестие. Совпадение подсвечивается зелёным, полоска показывает ожидание задержки. При возврате в анализатор остаётся последний снимок с возрастом кадра; он используется только для просмотра. Автоклик всегда работает по свежему захвату. Подсказка в панели состояния объясняет следующее действие, отсутствие цвета или проблему захвата.

## Проверка качества цвета

После выбора окна и сохранения цвета используйте «Снять мишень (3 сек.)»: окно тренажёра активируется автоматически, затем начинается трёхсекундный отсчёт для наведения на мишень. Аналогично нажмите «Снять фон (3 сек.)» и наведите прицел на участок без мишени. Если открыто меню, возобновите свободную игру. F9 отменяет ожидание. На время съёмки клики отключаются; после снимка захват остановлен. Если Windows отклонит переключение окна, съёмка отменится с пояснением; активируйте тренировку вручную и повторите снимок. Скрытое, отключённое или закрытое окно не запускает съёмку.

Блок показывает долю выбранного цвета в каждом снимке с текущим допуском, исключением перекрестия и порогом. Если мишень не проходит порог или фон тоже срабатывает, появится пояснение. После изменения допуска/цвета сохраните параметры — оценка пересчитается. После изменения размера области переснимите оба эталона.

Это сравнение двух отмеченных пользователем примеров, а не автоматическая разметка мишени и не гарантия для всего сценария. Повторяйте проверку на разных участках фона. Снимки хранятся только в памяти, сбрасываются при смене/закрытии окна и не разрешают клики; для включения ввода нужна обычная проверка по свежим кадрам.

Панель состояния уточняет причину отсутствия срабатывания: цвет отсутствует, доля ниже порога, совпадение только под исключённым перекрестием, триггер выключен, кнопки/модификаторы зажаты, задержка ещё идёт или непрерывное совпадение уже обработано. Ошибки захвата сопровождаются подсказкой о режиме окна или доступности области.

## Профили и сохранение

В простом режиме панель профилей видна сразу; в расширенном откройте её кнопкой «Профили». Введите название сценария и нажмите «Сохранить профиль»: сохраняются цвет, RGB/HSV, допуск, область и задержки. Одно название обновляет существующий профиль. Выберите профиль из списка и нажмите «Загрузить»; несохранённые изменения нужно сначала сохранить. Загрузка выключает клики, включает проверку без ввода и сохраняет текущую тему интерфейса.

«Сохранить всё» сохраняет настройки для следующего запуска. Пока цвет мишени не выбран, сохранение параметров не завершает шаг выбора цвета и не создаёт цветовой профиль. При неверном числе программа показывает допустимый диапазон, раскрывает скрытое поле и выделяет его для исправления. Именованный профиль обновляется отдельно кнопкой «Сохранить профиль»; подпись укажет, если его параметры были изменены. Внизу отображаются несохранённые изменения, успешное сохранение либо стандартные настройки. Профили хранятся локально в `%LOCALAPPDATA%\TriggerLab\profiles`, не содержат идентификаторов окон и не загружаются в сеть.

## Параметры

| Параметр | По умолчанию | Назначение |
|---|---:|---|
| ROI | 31 | Нечётная сторона области 5..101 пиксель |
| Игнор прицела | 3 | Исключить центральный квадрат 7×7; 0 отключает исключение |
| Порог | 3% | Доля совпадающих пикселей среди анализируемых, без исключённого центра |
| Сдвиг X / Y | 0 / 0 | Смещение точки прицела относительно центра окна, −2000..2000 |
| Задержка | 70 мс | Время подтверждённого совпадения, 1..2000 мс |
| Интервал | 50 мс | Минимальная пауза после завершённого клика, 50..2000 мс |
| Нажатие | 30 мс | Интервал между LeftDown и LeftUp, 5..150 мс; игровой цикл получает время увидеть нажатие |

Нажмите **«Сохранить всё»** для параметров области, времени, RGB и допуска. В расширенном режиме также доступно отдельное сохранение цвета. Изменение режима/цвета/параметров отключает триггер. При каждом запуске включена проверка без кликов, триггер выключен. Одно непрерывное совпадение даёт одно срабатывание; новое требует потери цвета и повторного совпадения. Ошибка захвата не считается потерей цвета. Задержка измеряется монотонными часами; фактическое срабатывание возможно позже на ближайшем свежем кадре.

Stop, Esc в анализаторе и глобальная **F9** выключают захват/триггер и отпускают программно нажатую кнопку. Если F9 занята, триггер не включается. Потеря фокуса, смена окна, зажатые модификаторы/кнопки, смена геометрии окна и недоступный захват блокируют ввод. Чёрный ROI не разрешает срабатывание в режиме прицела. «Отправлено» означает приём событий Windows, а не гарантированный выстрел стороннего приложения.

**Один клик TriggerLab не гарантирует один выстрел тренажёра.** «Нажатие» задаёт желаемое время между Down/Up; фактический интервал зависит от таймера и нагрузки, получение событий — от обработки ввода тренажёром. Реакцию оружия нужно проверять отдельно. Уменьшение до 5 мс не обеспечило стабильный одиночный выстрел в проверенной серии Kovaak’s до замены таймера; новый механизм в Kovaak’s пока не проверен.

В блоке «Состояние» строка «Нажатие» показывает интервал между вызовами отправки последних Down/Up и заданное для этого нажатия время. Она остаётся после остановки; «прервано» означает досрочное отпускание через Stop/F9 или другую блокировку. Проверка без ввода не создаёт измерение. Это время отправки из TriggerLab, а не время получения событий тренажёром; при новом запуске измерение сбрасывается.

Отпускание выполняется одноразовым таймером Windows в фоновом обработчике и не ждёт очереди сообщений интерфейса. Stop отменяет незавершённое нажатие и отпускает кнопку; повторная отмена не отправляет лишних событий. Планировщик Windows всё ещё может задержать обработчик, поэтому точные 5 мс не гарантируются.

## Цвет из изображения

«Из файла…» открывает PNG/JPEG/BMP/GIF/TIFF и предпросмотр. Выделите область мышью, выберите один из пяти основных оттенков и примените. «Палитра / область» повторно открывает последний файл. Диалог палитры использует выбранную тему, масштабирует шрифт и кнопки по DPI и помещается в рабочую область экрана. В узком окне оттенки расположены под изображением; нижние действия доступны прокруткой и клавишей Tab. Окно можно растягивать. Отмена сохраняет прежний цвет. Прозрачность показана шахматным фоном; alpha <128 игнорируется. Для GIF/TIFF анализируется первый кадр. Ограничения: файл до 64 МБ, размеры до 4096×4096. Пипетка работает без Start, с отсчётом 3 секунды; цвет при ошибке не меняется. Изображения не отправляются в сеть.

## Данные и проверка

Запуск/следующее действие, остановка F9 и текущий режим закреплены в верхней панели и остаются видны при прокрутке. Переключатели темы и простого/расширенного режима расположены компактно; при переходе по Tab поле показывается ниже панели. Основное окно при запуске помещается в рабочую область экрана. Размер текста и элементов следует масштабу Windows; при переносе между мониторами интерфейс обновляет DPI. В узком окне блоки перестраиваются в одну колонку, поля и кнопки помещаются по ширине. Используйте вертикальную прокрутку или колесо мыши для нижних блоков. При увеличении окна возвращается широкая разметка. Tab / Shift + Tab переводят фокус между элементами и показывают выбранное поле. Esc и F9 останавливают работу, в том числе когда фокус находится в поле ввода.

Переключатель **«Серая тема»** в шапке меняет светлое оформление на графитово-серое. Выбор сохраняется автоматически. Наведите указатель на параметры области и задержек, чтобы увидеть пояснение. Панель состояния отдельно показывает режим без кликов/реального ввода и долю найденного цвета; триггер доступен после выбора окна и запуска захвата.

Настройки: `%LOCALAPPDATA%\TriggerLab\analyzer-settings.json`, цвет: `selected-color.json`. Настройки отдельного стенда: `settings.json`. Последнее изображение хранится только в памяти. Для удаления закройте программы, удалите распакованную папку и при необходимости отдельно каталог настроек.

Команды `TriggerLab.exe --click-test` и `--center-click-test` проверяют реальный ввод в собственном временном окне. Вторая проверка использует белое перекрестие и ROI вдали от указателя, проверяет диагностику без ввода, задержку, длительность нажатия, повторное совпадение и отпускание при Stop. Отчёты создаются рядом с exe. При отсутствии интерактивного рабочего стола, внешних наложениях или вмешательстве пользователя проверка пропускается. Во время проверки около секунды не двигайте мышь.

Проверки центра и пошагового ввода также меняют фокус на другое собственное окно и закрывают выбранное окно во время нажатия: проверяются отпускание, выключение триггера и отсутствие новых Down в другом окне. Эти проверки занимают несколько секунд; оставьте мышь и клавиатуру свободными до их завершения.

Тест `--first-run-test` проверяет первый запуск, выбор цвета, ошибки полей, сохранение, повторный запуск, профили и обе темы. `--guided-click-test` проверяет переход от диагностики к реальному вводу через основную кнопку, повторное совпадение и остановку F9. Эти тесты, а также smoke/hover/center проверки анализатора, используют отдельные временные настройки и не изменяют личные данные. Подробности: `docs/first-run-validation.md`.

`--reference-test` проверяет съёмку эталонов в собственном временном окне: реальные трёхсекундные отсчёты, свежие кадры мишени и фона, исключение перекрестия, сохранность эталона при потере фокуса/чёрном кадре, отмену через обработчик F9 и сброс после закрытия окна. Ввод не отправляется, настройки изолированы. Отчёт — `reference-test-report.txt` рядом с exe. При недоступном рабочем столе, занятой F9 или вмешательстве в фокус/область проверка пропускается с кодом 77. Этот тест не подтверждает захват конкретного тренажёра.

`--pulse-test` отправляет 40 кликов в собственное временное окно: 20 с настройкой 5 мс и 20 с 30 мс. Отчёт `pulse-test-report.txt` показывает минимум, медиану и максимум интервала отправки, количество нажатий и отпусканий. Проверяется также отпускание при намеренной паузе интерфейса 100 мс. На несколько секунд оставьте мышь и клавиатуру свободными; при изменении фокуса/курсора тест пропускается. Параметры изолированы от личных настроек. Получение кликов сторонним тренажёром не проверяется.

В проекте 20 Windows-тестов и 9 переносимых тестов. Проверка конкретного тренажёра описана в `docs/trainer-validation.md`; наличие кнопки Aimlabs не означает подтверждённую совместимость со всеми его версиями. Поддержка Valorant/Vanguard не заявляется.

В Kovaak’s 3.9.10 подтверждено получение одиночного нажатия длительностью 30 мс в свободной игре Rxzu - FSClicking Hard: боезапас LG уменьшился с 3 до 2, статистика зарегистрировала один выстрел. Проверка использовала белое перекрестие как контрольный цвет; распознавание и попадание по мишени требуют настройки цвета конкретного сценария.

При проверке preview.3 в **Rxzu PivoTS STATIC** свежие эталоны дали 5,2% цвета на мишени и 0,0% на фоне при пороге 3%; диагностика не отправляла кликов, F9 остановила захват. Затем в серии из трёх попыток с настройкой нажатия **5 мс** TriggerLab считал по одному клику, а Kovaak’s — **3, 3 и 2 выстрела**. Фактическая длительность Down/Up и режим оружия отдельно не измерены; попадания не проверялись. Результаты относятся к этим условиям, параметры по умолчанию остаются 70/50/30 мс. Полный протокол и прежние прогоны: [проверки в тренажёрах](docs/trainer-validation.md).

## Сборка и дистрибутив

```powershell
cmake -S . -B build-release -G "Visual Studio 17 2022" -A x64 -DTRIGGERLAB_STATIC_RUNTIME=ON
cmake --build build-release --config Release --parallel 2
ctest --test-dir build-release -C Release --output-on-failure
./scripts/package-windows.ps1 -BuildDir build-release
```

Нужны CMake 3.20+, Visual Studio 2022 Build Tools и Windows SDK. В `dist/` создаются ZIP и SHA-256. GitHub Actions собирает Windows и переносимое ядро, архив — в артефакте `TriggerLab-portable-preview`. Архив содержит основной анализатор, отдельный стенд, инструкцию, условия использования и контрольные суммы; личных настроек и исходного кода в нём нет.

Закрытая лицензия: бесплатное личное некоммерческое использование готового приложения, без перепродажи и изменения. См. `LICENSE.txt`. История реализации — `CHANGELOG.md` и `docs/screen-analyzer-m0-m2.md`.
