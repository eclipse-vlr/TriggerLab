# Проверка сохранённых изображений

`TriggerLabImageCheck.exe` — диагностическая утилита Windows из сборки с тестами. Она читает изображение через WIC, вырезает указанную область и вызывает `aimColorMask`. Утилита не входит в переносимый ZIP приложения.

## Запуск

После сборки с `TRIGGERLAB_BUILD_TESTS=ON`:

```powershell
.\build\Release\TriggerLabImageCheck.exe 'C:\Samples\target.png' 255 0 0 0 0
```

Пример проверяет красный цвет в области 31×31 с левым верхним углом 0/0. Подставьте собственный файл, RGB и координаты.

```text
TriggerLabImageCheck IMAGE R G B X Y [SIDE [TOLERANCE [IGNORE [PERCENT]]]]
```

`X/Y` — левый верхний угол области в исходном изображении, координаты начинаются с нуля. Значения по умолчанию: сторона 31, RGB-допуск 24, исключение центра радиусом 3 (квадрат 7×7), порог 3%. Область должна целиком помещаться в кадр. Дополнительные параметры задаются по порядку и проверяются по ограничениям анализатора.

Результат — строка JSON с размерами кадра, областью, цветом, параметрами, числом совпадений, процентом, `found` и числом исключённых совпадений. Код 0 означает успешный анализ, включая `found=false`. Код 1 означает ошибку аргументов, декодирования или области; пояснение выводится в stderr.

Поддерживаются PNG/JPEG/BMP/GIF/TIFF: первый кадр, до 64 МБ, размеры до 4096×4096. Прозрачные пиксели в проверяемой области отклоняются. Настройки пользователя и HSV-профили не загружаются; окна, захват экрана и системный ввод не используются.

## Интерпретация

Сравнивайте снимок мишени и несколько участков фона при одинаковых параметрах. Доля цвета показывает покрытие области, а `found` дополнительно требует совпадения в центре либо вокруг исключённого перекрестия. Цвет у края области сам по себе не разрешает срабатывание.

Без разметки содержимого `found=true` не доказывает правильное распознавание объекта. Для проверки в тренажёре нужна [отдельная серия](trainer-validation.md).

## Автоматические проверки

```powershell
ctest --test-dir build -C Release --output-on-failure -R '^triggerlab_image_check_tests$'
```

[Самопроверка утилиты](../tests/win32_image_check.cpp) использует собственный временный каталог: проверяет BMP с путём на кириллице, BGRA/RGB, положение области, долю, границы аргументов, повреждённый и отсутствующий файл, выход области за кадр, большие координаты и прозрачность. Цветовые маски дополнительно проверяются [синтетическими сценами](color-scene-validation.md).
