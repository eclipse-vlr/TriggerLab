# Проверка 0.4.0-preview.2, 14 октября 2026

## Kovaak’s 3.9.10 на этом компьютере

- Kovaak’s установлен через Steam. При первом запуске отсутствовал DirectX Runtime; штатный установщик Steam с действительной подписью Microsoft установлен с разрешения пользователя. Затем тренажёр запустился.
- Поиск окна и ручное управление проверены в интерфейсе. Для технической проверки выбран режим свободной игры, а не рейтинговое испытание.
- Реальный захват вокруг центра клиентской области подтверждён контрольным белым перекрестием: временные параметры ROI 5, игнор 0, порог 1%, RGB 255/255/255. Это проверка захвата, не рекомендуемый профиль для обнаружения мишеней.
- При включённой проверке без кликов счётчик диагностики увеличился на один, отправленных кликов было ноль.
- При реальном вводе Windows приняла один клик; визуальная реакция конкретного оружия на первоначальную мгновенную пару событий не подтверждена. Затем добавлена регулируемая длительность нажатия, по умолчанию 30 мс. Это повышает совместимость с игровым циклом, но не заменяет проверку выстрела/попадания на конкретном сценарии.
- F9 выключила триггер и захват. При потере фокуса тренажёр открывает меню; после активации нужно вручную возобновить свободную игру. Перед входом в меню триггер следует выключать.

## Автоматические проверки

Режим центра проверен в отдельном собственном окне с белым перекрестием, физическим курсором вне ROI и цветной мишенью вокруг центра. В последней интерактивной проверке первое нажатие доставлено через 122 мс, повторное — через 138 мс, длительность нажатия составила 47 мс при запрошенных 30 мс. Проверка без ввода не отправила событий; остановка во время незавершённого нажатия доставила отпускание (три нажатия, три отпускания).

Обычные тесты геометрии, маски, параметров, сохранения, изображений и обоих интерфейсов проходят. Тест реального ввода под системным курсором может пропускаться из-за внешнего наложения/подсветки курсора; проверка сверяет эталонные пиксели до отправки ввода. Отсутствие интерактивного рабочего стола или вмешательство пользователя также даёт пропуск, а не подтверждение совместимости.

## Aimlabs

Режим клиентского центра и поиск процесса/окна реализованы, но Aimlabs на этом компьютере не проверен. Нельзя считать поддержку подтверждённой только по наличию кнопки. Для проверки нужны отдельная пользовательская задача, видимый ROI и подтверждение реакции на реальное нажатие. Полноэкранный захват, обработка искусственного ввода, цвет мишеней и перекрестие могут отличаться.

## Границы проверки

Не проверены все сценарии/оружия Kovaak’s, все версии Aimlabs, HDR/эксклюзивный полноэкранный режим и все настройки экранов. Запись «Отправлено» означает принятие событий Windows, а не ответ игрового движка. На каждом запуске реальный ввод выключен; начинать следует с диагностики и цвета конкретной мишени.
