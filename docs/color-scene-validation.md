# Проверка цвета на синтетических изображениях

[triggerlab_color_scene_tests](../tests/color_scene_tests.cpp) создаёт изображения в памяти из фиксированных цветов и геометрии. Тест переносим, не открывает окна, не захватывает экран, не отправляет ввод и не читает настройки пользователя.

После сборки из корня проекта:

```powershell
ctest --test-dir build -C Release --output-on-failure -R '^triggerlab_color_scene_tests$'
```

Для вывода каждой сцены добавьте `-V`. Результат содержит число совпадающих пикселей, долю и `found`; итоговая строка сообщает число сцен и ошибок.

## Проверяемое поведение

Для стандартной области 31×31 с исключением центра 7×7 учитываются 912 пикселей. Порог покрытия и наведение центром проверяются вместе.

| Сцена | Ожидаемый результат |
|---|---|
| Тёмный фон, серый градиент и синяя текстура | Нет совпадений в RGB и HSV |
| Мишень 6×6 в пяти положениях у края области | 36 совпадений, 3,947%; `found=false`, поскольку центр не наведён |
| Цветная обводка 9×9 вокруг белого центра 7×7 | 32 учитываемых пикселя; `found=true` |
| Маленькая мишень 3×3 | 9 совпадений, ниже стандартного порога |
| 27 и 28 совпадений при исключённом центре и подтверждённом наведении | 27 недостаточно для 3%; 28 достаточно |
| Исключение центра выключено | Проверяется центральный пиксель; для 3% от 961 пикселя нужно 29 совпадений |
| Только цветное перекрестие 7×7 | При исключении центра срабатывания нет; без исключения его цвет участвует в обнаружении |
| Отклонение каналов RGB на 24 и 25 | При допуске 24 граница включена, отклонение 25 отклонено |
| Сглаженные края и затемнённый жёлтый | Проверяются заданные границы RGB и HSV |
| Красный возле границы 0°/360° | Проверяется круговая разница оттенка |
| Фон того же цвета и площади, что мишень | Сравнение сообщает риск совпадения фона |

Тест также сверяет размер и двоичные значения маски, положение цветных пикселей, знаменатель доли и число совпадений в исключённом центре. Исчерпывающий набор параметров и ожидаемых значений задан в исходнике теста.

## Ограничения

Это проверка заданных пикселей. Она не подтверждает распознавание объектов: фон и мишень одинакового цвета для этого метода неразличимы.

Сцены не заменяют проверку игровых изображений, HDR, JPEG-сжатия, движения и освещения. Декодирование проверяется [отдельной утилитой](offline-image-check.md), захват и ввод — Windows-тестами. Для тренажёра используется [методика ручной проверки](trainer-validation.md).
