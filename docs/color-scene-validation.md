# Проверка цвета на синтетических изображениях

Тест `triggerlab_color_scene_tests` создаёт 53 изображения в памяти из фиксированных цветов и геометрии. Он переносим, не открывает окна, не захватывает экран, не отправляет ввод и не читает личные настройки. Исходные сцены заданы в `tests/color_scene_tests.cpp`; случайных чисел и внешних файлов нет.

Запуск из корня проекта после сборки:

```powershell
ctest --test-dir build-release -C Release --output-on-failure -R '^triggerlab_color_scene_tests$'
```

Для вывода результата каждой сцены используйте `ctest --test-dir build-release -C Release -V -R '^triggerlab_color_scene_tests$'`. Вывод содержит число совпадающих пикселей, долю и решение; итог — `scenes=53 failures=0` при успешном выполнении.

## Условия и ожидаемые результаты

По умолчанию область 31×31, исключён центральный квадрат 7×7, порог 3%. Анализируются 912 пикселей. Тест проверяет точное число совпадений, знаменатель доли, решение, двоичную маску и число совпадений под исключённым перекрестием. Сравнение отмеченных мишени/фона проверяется отдельно.

| Сцена | Ожидаемый результат |
|---|---|
| Тёмный фон, серый градиент от чёрного до белого, фиксированная синяя текстура | Нет совпадений в RGB и HSV |
| Мишень 6×6 в пяти положениях на каждом из трёх фонов | 36 совпадений, 3,947%, найдена в RGB и HSV |
| Маленькая мишень 3×3 | 9 совпадений, 0,987%, ниже порога |
| Граница порога при исключённом центре | 27 пикселей недостаточно; 28 достаточно |
| Те же 28 пикселей без исключения центра | Ниже 3%; для 961 анализируемого пикселя нужно 29 |
| Только цветное перекрестие 7×7 | 49 совпадений исключены, срабатывания нет; при отключённом исключении оно срабатывает |
| Обводка 9×9 вокруг белого центра 7×7 | 32 совпадения, 3,509%, найдена |
| Отклонение каналов RGB на 24 и 25 от выбранного цвета | Граница 24 включена, отклонение 25 отклонено |
| Сглаженная мишень: ядро 4×4 и смешанные с фоном края до 6×6 | При RGB-допуске 24 остаётся 16 пикселей и порог не пройден; в данном HSV-примере с допуском V=0,4 находятся 36 |
| Затемнённый жёлтый 200/200/0 вместо 255/255/0 | RGB-допуск 24 не проходит; HSV с допуском V=0,25 проходит |
| Красный около границы оттенка 0°/360° | Круговая разница менее 3° проходит; более 3° не проходит |
| Участок фона того же цвета и площади, что мишень | Совпадение на обоих примерах; сравнение сообщает `backgroundFound=true` |

Первый блок фонов и положений содержит 36 сцен, остальные проверки — 17. Цветовая маска использует существующий алгоритм; тесты не меняют его параметры по умолчанию.

Локальная проверка 18 октября 2026: сборка Release успешна, общий CTest прошёл 21/21 без пропусков. После дополнительных проверок положения мишени в маске новый тест пересобран и повторно прошёл отдельно. `git diff --check` выполнен успешно. Linux в этом этапе не запускался.

## Ограничения

Это проверка заданных пикселей, а не распознавания объектов: одинаковый цвет на фоне и мишени неразличим для текущего метода. Более широкий HSV-допуск помогает только в показанных условиях и может увеличить ложные совпадения на другом фоне.

Сцены не подтверждают работу на всех игровых изображениях, HDR, JPEG-сжатии, движении или разных настройках освещения. Сглаживание представлено готовыми непрозрачными смешанными пикселями. Декодирование файлов проверяется другими тестами; нажатия и захват тренажёра здесь не проверяются. Для реального сценария нужны свежие примеры мишени и нескольких участков фона.
