# TriggerLab 0.4.5

- Исправлены распознавание на точном пороге и переход от проверки к кликам в расширенном режиме.
- Чёрный кадр приостанавливает распознавание; F9 останавливает захват во всех режимах.
- Добавлены предупреждение о повреждённых настройках и прокрутка тренажёра при высоком DPI.

Windows 10/11 x64. Распакуйте ZIP и запустите TriggerLab.exe.
