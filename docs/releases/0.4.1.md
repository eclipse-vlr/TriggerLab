# TriggerLab 0.4.1

## Запуск на Windows

Скачайте **TriggerLab-0.4.1-windows-x64.zip** из Assets, распакуйте архив и откройте **TriggerLab.exe**. Windows 10/11 x64; установка CMake и Visual Studio для готовой программы не нужна. **Source code** — исходники для самостоятельной сборки.

## Изменения

- При ошибке `build-windows.bat` окно остаётся открытым, вывод сохраняется в `build-windows.log`.
- Скрипт проверяет CMake/CTest и объясняет необходимые инструменты Visual Studio 2022.
- После успешной сборки приложение запускается из своей рабочей папки.
- Windows CI выполняет сам BAT и проверяет наличие живого главного окна; Linux CI проверяет переносимое ядро.

ZIP содержит TriggerLab, отдельный тренировочный стенд TriggerLabTrainer, инструкцию, лицензию и контрольные суммы. Рядом с ZIP опубликован файл SHA256 для проверки архива.

Причина исходного сбоя сборки на пользовательском компьютере без его журнала не установлена; релиз улучшает диагностику и позволяет запускать готовую программу без локальной сборки.
