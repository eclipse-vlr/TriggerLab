# TriggerLab 0.4.2

Скачайте **TriggerLab-0.4.2-windows-x64.zip** из Assets, распакуйте и запустите **TriggerLab.exe**. Windows 10/11 x64; установка не требуется.

- Исправлено восстановление после отказа отпускания кнопки мыши: новые клики блокируются, Stop/F9 и служебный таймер повторяют отпускание.
- Частичное перекрытие области прицела другим окном больше не допускается к распознаванию и вводу.
- Режим HSV и его допуски сохраняются после перезапуска. Старые RGB-профили поддерживаются.

Добавлены регрессионные проверки и CI с ASan/UBSan. Проверки выпуска: Windows — 24 теста, Linux — 10, ASan/UBSan — 10.

ZIP включает TriggerLab, TriggerLabTrainer, инструкцию и лицензию. Рядом опубликован SHA256.
