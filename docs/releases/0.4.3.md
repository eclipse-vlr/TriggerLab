# TriggerLab 0.4.3

Скачайте **TriggerLab-0.4.3-windows-x64.zip** из Assets, распакуйте и запустите **TriggerLab.exe**. Windows 10/11 x64; установка не требуется.

- Исправлен ранний клик: цвет у края области больше не считается наведением на мишень.
- Распознавание работает вокруг белого перекрестия в форме плюса: добавлена проверка по диагоналям.
- Захват продолжается во время нажатия, поэтому исчезновение цели и повторное наведение не теряются. Исправлены пропуски при медленном захвате свежих кадров.
- После F9 остаются счётчики кадров, совпадений и причина последней паузы.
- Рядом с расширенными параметрами появились видимые «?» с подробными подсказками. Исправлено отображение подсказок на common-controls v5.
- Включены исправления аудита: общий допуск к вводу, диагностика ошибок запуска и изоляция конкурентного сохранения файлов.

Проверки выпуска выполняются в Windows, Linux и с ASan/UBSan. В Kovaak’s подтверждено диагностическое срабатывание под белым перекрестием; серия реальных попаданий в игре отдельно не проверена. Личные настройки и профили совместимы с предыдущей версией.

ZIP включает TriggerLab, TriggerLabTrainer, инструкцию и лицензию. Рядом опубликован SHA256; внутри архива есть версия, исходный коммит и контрольные суммы файлов.
