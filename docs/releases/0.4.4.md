# TriggerLab 0.4.4

Скачайте **TriggerLab-0.4.4-windows-x64.zip** из Assets, распакуйте и запустите **TriggerLab.exe**. Windows 10/11 x64; установка не требуется. **TriggerLabTrainer.exe** — отдельный тренировочный стенд.

Выпуск включает рефакторинг проекта из PR #6:

- Тестовые сценарии вынесены в отдельные EXE; переносимый ZIP собирается с выключенными тестовыми целями.
- Анализатор, палитра и тренажёр используют общий модуль владения буфером изображения.
- Разбор настроек объединён; чтение прежних форматов и профилей сохранено.
- Версия в интерфейсе тренажёра соответствует версии сборки.
- Обновлены инструкция, архитектура и правила разработки; исторические протоколы испытаний сохранены в репозитории.

Настройки, профили и привычные действия совместимы с 0.4.3. Клики при запуске выключены. F9 или «Остановить» останавливают захват и ввод.

CI проверяет Windows/GUI, переносимое ядро на Linux, ASan/UBSan и форматирование. Сборка выпуска использует предупреждения как ошибки. Ручная проверка этого выпуска в Kovaak’s/Aimlabs на пользовательском компьютере отдельно не проводилась.

В ZIP находятся приложения, инструкция, лицензия, список изменений, VERSION.txt с исходным коммитом и SHA256SUMS.txt. Рядом с архивом опубликован SHA256.
