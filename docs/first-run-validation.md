# Проверка первого запуска

Автоматическая проверка `triggerlab_first_run` запускает отдельный `TriggerLabUiTests.exe` с временным каталогом. Она проверяет начальные состояния, сохранение, повторное открытие, разметку и работу контролов при разных DPI и темах.

```powershell
ctest --test-dir build -C Release -R "first_run|window_picker|help_popup" --output-on-failure
```

Перед выпуском вручную проверьте чистый запуск ZIP, выбор окна и цвета, сохранение, диагностику без ввода, Stop/F9 и повторное открытие. На дисплеях с 100/125/150/200% проверьте читаемость, доступность действий и переход между мониторами.

Исторические прогоны содержат результаты для конкретных прежних сборок, в том числе непрошедшие проверки и ограничения среды: [архив](history/first-run-validation-before-refactor.md).
