# Защита main

На 28 октября 2026 в репозитории активен [ruleset main](https://github.com/eclipse-vlr/TriggerLab/rules/25941001).

Правило применяется к основной ветке: изменения проходят через PR; удаление ветки и force push запрещены; постоянных обходов нет. Для слияния требуются успешные проверки `windows`, `portable-core` и `Portable core with ASan and UBSan`. Число обязательных одобрений — 0; обязательное обновление ветки перед слиянием выключено.

Проверка `C++ style` также выполняется в CI и блокирует автоматическую публикацию релиза. Она пока не включена в обязательные проверки ruleset.

Настройки редактируются владельцем в [Settings → Rules → Rulesets](https://github.com/eclipse-vlr/TriggerLab/settings/rules). Наличие этого документа само по себе не меняет защиту ветки.
